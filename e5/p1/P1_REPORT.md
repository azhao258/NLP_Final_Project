# P1：解释损失渐增的验证结果

结论：本次单种子、750 次更新的 P1 没有形成明确的答案或解释质量收益。保留 control_v1，不将 P1 升级为新基线；建议下一项按原计划独立检验 P2，不与 P1 叠加。此次分析没有读取测试集或启动新训练。

## 实验与证据范围

P1 保留完整解释前缀，从原 shared_init 开始。第 1 次更新的解释损失系数为 0.1，第 250 次达到 1.0，之后保持 1.0；其他训练设置沿用 v1。整个训练过程的平均系数为 0.85，因此该实验同时改变了监督时序和累计权重，不能单独归因于时序。

本报告读取 `server_backup_p1/` 下两组完整验证导出和两组 P0 原始记录。200 题的 ID、问题、答案、参考算式、监督位置与本地验证集逐条核对；P0 的 32 个训练样本、32 个验证样本及跨题 donor 配对在两模型间一致。答案、解释指标及主要 P0 统计均从原始记录复算。校验全部通过。

验证导出与 P0 配置中的 checkpoint 哈希相互一致：

- control：`02ce2c7589a4d12f3f04702f50bb25e298751f734bcb82c5c2ce53062d3bdc39`，与 frozen_v1 一致。
- P1：`4276c57a336117c29e8592c98ed1f4262fe37b05c3e3d8ed287bef9fcd2871f8`。

本次下载未包含模型权重和完整训练日志，因此未重新计算远程权重文件哈希或独立审计整个训练过程。用户提供的末步日志显示 750 次更新完成、系数 1.0、训练期验证 6/200；其中 elapsed_seconds 约 4051 秒，是最后一条训练日志的计时，不应替代包含最后验证和保存开销的 sessions.jsonl 总时长。

## 完整验证集：没有明确收益

| 指标 | control | P1 |
|---|---:|---:|
| 答案正确 | 6/200（3%） | 6/200（3%） |
| 严格步骤匹配 | 6/478 | 6/478 |
| 限定算式兼容匹配 | 9/478 | 10/478 |
| 操作数匹配 | 10/478 | 11/478 |
| 运算符匹配 | 190/478 | 190/478 |
| 中间结果匹配 | 26/478 | 19/478 |
| 生成算式自身成立 | 1000/1000 | 1000/1000 |
| 解释生成截断 | 0 | 0 |

478 是有效参考位置数；1000 是全部生成位置数，含没有参考步骤的 PAD 位置。自身算术成立不代表与题目对应。限定兼容和操作数匹配使用已有 E4 规则（包括操作数多重集合），并非通用数学语义等价或严格首操作数跨度指标。

逐题比较：85/200 个数值答案改变。两模型共同答对 2 题，各自独有的正确题都是 4 题；P1 新答对 4 题，同时失去 control 原本答对的 4 题。严格步骤匹配新增 5 个、丢失 5 个，净变化为零。

## 固定算式问题仍存在

每个位置的不同解释文本数量，两组均为 `[5, 2, 2, 2, 2]`。

例如 slot 1：control 的 200 条输出中，188 条为 `3*2=6`，12 条为 `2*3=6`；P1 则分别为 59 条和 141 条。只是两个等价模板的频率发生变化，没有增加题目特异性。

两模型共有 590/1000 个位置的规范化解释文本不同，其中 455 个变化仍通过限定等价检查。不能把这种文本变化当作解释改进。

## 同样本 P0：敏感性不等于有效利用

下表为验证子集 32 题、71 个有效解释位置。NLL 差值均为“交换 − 正常”，正值才支持原题 latent 在该指标上更好。

| 指标 | control | P1 |
|---|---:|---:|
| 交换后数值答案改变 | 17/32 | 16/32 |
| 正常 / 交换后答对 | 0 / 0 | 0 / 0 |
| 平均答案 NLL 差值 | -0.04218 | -0.00551 |
| 解释文本改变 | 22/71 | 38/71 |
| 改变中仍限定等价 | 1/22 | 26/38 |
| 改变且未通过限定等价 | 21/71 | 12/71 |
| 平均解释 NLL 差值 | -0.002626 | -0.001636 |
| 正常 / 交换后解释严格匹配 | 1 / 0 | 1 / 1 |

P1 的答案 NLL 差值更接近零，但仍未出现原题 latent 的正向平均优势。P1 的解释文本变化率提高，主要伴随更多等价算式替换；不能据此声称学到了更强的步骤语义。这里的“未通过限定等价”不代表已经证明语义不同。

训练子集的数值答案变化两组均为 10/32，均为正常及交换后 0 题正确；平均答案 NLL 差值为 -0.02655 / -0.02118，平均解释 NLL 差值为 +0.004113 / -0.006221。也没有一致的正向收益。

## 梯度诊断

验证子集共享参数上的答案—解释平均余弦由 +0.1171 变为 +0.1258，负余弦比例均为 3/32。P1 终点仍不支持普遍、强烈的梯度冲突假设。

解释梯度在 reasoner 上的平均范数由 0.07242 变为 0.06291，在 projector 上由 2.19716 变为 2.11069。作用分布仍明显不均衡。范数受参数化影响，不能直接推断信息被阻断或某模块没有学习。

## 判断与下一步

P1 没有改善主要指标：答案和严格匹配持平，限定兼容只增加 1 个位置，中间结果匹配反而减少 7 个。它维持了算术自洽，但未解决固定模板与题目脱节的问题。当前没有理由为 P1 追加种子训练或提前运行测试集。

下一步建议独立检验 P2：仍从 shared_init 开始、完整前缀、750 次更新，只对每条算式首个操作数的完整 token 跨度赋权 2，其他 token 权重 1，按有效 token 权重总和归一化。不沿用 P1 权重，也不叠加渐增。多 token 数字、小数、负号及合并尾部算式均需覆盖。这个方向仍是待检验的工程假设。

限制：单种子、小样本诊断；P0 关闭 dropout，只观察最终 checkpoint；跨题交换属于分布外干预。完整验证使用 BF16 权重，P0 使用 FP32 master + BF16 autocast，应分别在同一口径内比较。历史 control 选择曾参考测试集，该限制继续保留。不作显著性、泛化提升或内部推理忠实性的声明。
